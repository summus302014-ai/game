# HEXWORLD
Гексагональная 3D sandbox-игра с AI-спутником Гексом.

## Запуск (Windows)
1. Установите Node.js LTS: https://nodejs.org
2. Скачайте проект и распакуйте в любую папку.
3. Дважды кликните `start.bat`. При первом запуске откроется Блокнот с файлом `.env` — впишите API-ключ после `LLM_API_KEY=`, сохраните и закройте.
4. Игра откроется в браузере (http://localhost:3000).

Ключ хранится только в `.env` (он в `.gitignore` и не попадает в репозиторий). Зависимостей нет.
